# VSB · Soluções técnicas — materiais de marca

Os SVGs são vetoriais, com as letras em curvas e sem dependência de fontes instaladas. Cores originais: petróleo `#123B4A`, cobre `#C97941`, grafite `#171A1C`, chumbo `#24282B`, off-white `#F5F3EE`, cinza `#E5E7E6` e branco `#FFFFFF`.

| Arquivo | Uso |
| --- | --- |
| `vsb-positiva.svg` | Marca principal sobre fundo claro |
| `vsb-horizontal.svg` | Cópia da marca principal — 240 × 64 |
| `vsb-negativa.svg` | Marca clara e divisor cobre para fundo escuro |
| `vsb-monocromatica.svg` | Marca integral em grafite |
| `vsb-monocromatica-branca.svg` | Marca integral em branco |
| `vsb-avatar.svg` | Perfil Instagram e WhatsApp — 400 × 400 |
| `vsb-simbolo.svg` | Símbolo V auxiliar — 112 × 112 |
| `vsb-favicon.svg` | Ícone para navegador — 64 × 64 |
| `vsb-cartao-frente.svg` | Composição de cartão, frente — proporção 90 × 50 mm |
| `vsb-cartao-verso.svg` | Composição de cartão, verso — proporção 90 × 50 mm |
| `vsb-assinatura.svg` | Assinatura visual — 760 × 190 |
| `vsb-orcamento.svg` | Modelo visual de orçamento — proporção A4 |
| `vsb-post-instagram.svg` | Publicação institucional — 1080 × 1350 |
| `og-vsb.svg` | Imagem para compartilhamento do site — 1200 × 630 |
| `vsb-identidade-prancha.svg` | Prancha de apresentação — 1600 × 1870 |

Preservar as proporções. Usar o cobre como detalhe e o off-white como fundo predominante. O cobre sobre branco ou off-white não tem contraste suficiente para textos pequenos; usar petróleo ou grafite.

Os cartões não possuem sangria. Impressão, bordado, gravação e adesivos precisam de preparação específica para o processo de produção. Os SVGs são arquivos de desenho, não garantias de correspondência entre cor na tela, tinta e tecido.

Os materiais de contato usam Neto e Radioamador Classe A conforme o briefing. Telefone e e-mail não confirmados foram omitidos. Nas aplicações digitais, os dados de contato devem também existir como texto selecionável e links acessíveis.

O guia completo está em `../guia/identidade-visual.md`, neste pacote.
